UI

ui-design-guide

说"这个页面太乱了"的时候用

查看仓库 →

分析现有 UI 问题，给出多个方案，用 HTML 原型直接展示效果，确认后才改代码。 支持截图输入，不用先描述清楚问题在哪。

分类：设计 支持截图输入

怎么工作的

  • 上传截图或描述问题，先分析现有 UI 具体乱在哪
  • 给出多个可选方案，而不是直接改代码
  • 每个方案用 HTML 原型展示，能点、能看效果
  • 确认方案后才真正动代码

目标

让"改样式"这件事先对齐方向，再动手，省掉改了又推翻的来回成本。
