作品与 Skill

能把重复劳动交出去的东西

把写 PRD 的规则固化成开源工具，又给 Claude Code 写了一组 Skill，把每天重复的活儿——出原型、画流程图、维护知识库——交给它做。都是自用，不是演示。

2026 PRD Generator 把我写 PRD 的规则固化成工具。上传原型图或粘贴需求，生成结构化初稿，我只回答判断题。 最花时间的不是让模型写得更多，而是让它少写——不写 UI 布局、不写视觉样式，那是设计稿的职责。 个人项目 · 开源 · Next.js + Claude + Supabase
PRD prd-skill 写产品需求文档。按复杂度分三档（≤20 行 / ≤50 行 / 按需），带 Triage 流程和验收标准。目标不是写得最全，是让工程师不用反复来问。 7 个参考文件 · 模板 + 检查清单
知识库 product-wiki 一个知识库编译器。把飞书里堆着的播客访谈、文章等原始资料，自动编译成人物摘要 + 概念文章 + 索引。 飞书 API · 增量更新
设计 ui-design-guide 说「这个页面太乱了」的时候用。分析现有 UI 问题 → 给多个方案 → 用 HTML 原型展示 → 确认后才改代码。 支持截图输入
原型 html-prototype 把 PRD 或设计方案变成单文件可交互原型。不用说「用 HTML」，说「做个页面看看」就行。 单文件 · 可点击
图 mermaid-flowchart 把 PRD 和功能文档转成 Mermaid 流程图、架构图、状态图。 Mermaid
内部 octo-prd prd-skill 的定制版，接上了团队的 Issue triage 与评审流转。因含公司内部信息，不开源。 不公开
